부가세 계산기

공급가액을 넣으면 부가세와 합계금액이, 합계금액을 넣으면 공급가액과 부가세가 나온다. 견적서와 세금계산서를 만들 때 쓴다.

일반과세자 기본 세율

계산식

부가세 = 공급가액 × 10%
합계금액(공급대가) = 공급가액 + 부가세 = 공급가액 × 1.1
공급가액 = 합계금액 ÷ 1.1

합계금액 110,000원이라면 공급가액은 100,000원, 부가세는 10,000원이다. 합계금액에서 부가세를 구할 때는 11로 나눈 값이라고 기억해 두면 편하다.

알아둘 점

  • 일반과세자의 세율을 기준으로 한 계산이다. 간이과세자는 업종별 부가가치율을 곱해 세액을 계산하므로 다르다.
  • 면세 품목은 부가세가 없다.
  • 원 단위 미만은 반올림한다.

자주 묻는 질문

공급가액과 공급대가는 어떻게 다른가?

공급가액은 부가세를 뺀 금액이고, 공급대가는 부가세를 포함한 금액이다.

부가세를 포함한 금액에서 부가세만 구하려면?

합계금액을 11로 나누면 부가세이다. 110,000원이면 10,000원이다.

세금계산서 금액은 어느 쪽인가?

세금계산서에는 공급가액과 세액을 따로 적는다.

간이과세자도 같은 방식인가?

아니다. 간이과세자는 공급대가에 업종별 부가가치율과 10%를 곱해 납부세액을 계산한다.
