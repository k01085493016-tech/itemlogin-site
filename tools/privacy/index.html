개인정보처리방침

입력한 값은 서버로 보내지 않는다.

1. 수집하는 정보

아이템로그 계산기는 회원가입이 없고, 이름·연락처 같은 개인정보를 수집하지 않는다. 계산기에 입력한 금액, 날짜, 생년월일은 사용자의 브라우저 안에서만 계산되며 서버로 전송되거나 저장되지 않는다.

2. 자동으로 생기는 정보

사이트를 제공하는 GitHub Pages가 접속 기록(IP 주소, 접속 시각 등)을 서비스 운영을 위해 처리할 수 있다. 이 사이트는 해당 기록을 직접 열람하거나 이용하지 않는다.

3. 광고와 쿠키

현재 이 사이트에는 광고와 방문자 분석 도구가 없다. 앞으로 구글 애드센스 같은 광고나 분석 도구를 도입하면 이 페이지에 사용하는 서비스, 쿠키 사용 목적, 거부하는 방법을 먼저 적은 뒤 적용한다. 구글 광고 쿠키는 구글의 광고 설정(adssettings.google.com)에서 관리할 수 있다.

4. 외부 링크

다른 사이트로 연결되는 링크가 있을 수 있으며, 연결된 사이트의 개인정보 처리는 해당 사이트의 방침을 따른다.

5. 문의

개인정보 관련 문의는 인스타그램 @iteml_og DM으로 보내 달라.
